# MO.1.3 - Kiểm soát Rủi ro Thanh khoản

**Khối:** Quản lý Rủi ro (Risk Management)

## 1. Mục đích (Purpose)
Thực hiện quy trình kiểm soát rủi ro thanh khoản nhằm đảm bảo hiệu quả hoạt động. `[FACT]` (Nguồn: S-T1-004)

## 2. Trigger (Kích hoạt)
Định kỳ hoặc khi có yêu cầu phát sinh.

## 3. Các bước (Steps / Tasks)
1. Thu thập dữ liệu cho kiểm soát rủi ro thanh khoản
2. Phân tích và đánh giá kiểm soát rủi ro thanh khoản
3. Lập báo cáo kiểm soát rủi ro thanh khoản
4. Trình duyệt phê duyệt kiểm soát rủi ro thanh khoản
5. Lưu trữ hồ sơ kiểm soát rủi ro thanh khoản

## 4. Input / Output
Input: Dữ liệu thị trường/hệ thống. Output: Báo cáo, hồ sơ hoàn thiện.

## 5. Vai trò (Roles)
Chuyên viên, Trưởng bộ phận, Ban Giám đốc.

## 6. Hệ thống (Systems)
Bloomberg, FiinPro, ERP, Hệ thống lõi (Core system).

## 7. Tần suất (Frequency)
Hàng ngày / Tuần / Tháng.

## 8. Điểm gãy điển hình (Pain points)
Thao tác thủ công, phân tán dữ liệu, thiếu tích hợp hệ thống tự động. `[INFERENCE]` Suy luận từ thực trạng ngành.

## 9. Ràng buộc pháp lý (Legal)
