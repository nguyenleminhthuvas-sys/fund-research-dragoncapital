# BO.1.3 - Tính toán Phí Quản lý

**Khối:** Kế toán Quỹ & Tính NAV (Fund Accounting)

## 1. Mục đích (Purpose)
Thực hiện quy trình tính toán phí quản lý nhằm đảm bảo hiệu quả hoạt động. `[FACT]` (Nguồn: S-T1-004)

## 2. Trigger (Kích hoạt)
Định kỳ hoặc khi có yêu cầu phát sinh.

## 3. Các bước (Steps / Tasks)
1. Thu thập dữ liệu cho tính toán phí quản lý
2. Phân tích và đánh giá tính toán phí quản lý
3. Lập báo cáo tính toán phí quản lý
4. Trình duyệt phê duyệt tính toán phí quản lý
5. Lưu trữ hồ sơ tính toán phí quản lý

## 4. Input / Output
Input: Dữ liệu thị trường/hệ thống. Output: Báo cáo, hồ sơ hoàn thiện.

## 5. Vai trò (Roles)

## 6. Hệ thống (Systems)

## 7. Tần suất (Frequency)
