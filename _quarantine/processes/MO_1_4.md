# MO.1.4 - Stress Testing Danh mục

**Khối:** Quản lý Rủi ro (Risk Management)

Thực hiện quy trình stress testing danh mục nhằm đảm bảo hiệu quả hoạt động. `[FACT]` (Nguồn: S-T1-004)

2. Phân tích và đánh giá stress testing danh mục
3. Lập báo cáo stress testing danh mục
4. Trình duyệt phê duyệt stress testing danh mục
5. Lưu trữ hồ sơ stress testing danh mục

## 4. Input / Output
Input: Dữ liệu thị trường/hệ thống. Output: Báo cáo, hồ sơ hoàn thiện.
