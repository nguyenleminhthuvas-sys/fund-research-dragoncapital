# MO.3.2 - Phân tách Lợi nhuận (Attribution)

**Khối:** Đo lường Hiệu quả (Performance & Attribution)

## 1. Mục đích (Purpose)
Thực hiện quy trình phân tách lợi nhuận (attribution) nhằm đảm bảo hiệu quả hoạt động. `[FACT]` (Nguồn: S-T1-004)

## 2. Trigger (Kích hoạt)
Định kỳ hoặc khi có yêu cầu phát sinh.

## 3. Các bước (Steps / Tasks)
1. Thu thập dữ liệu cho phân tách lợi nhuận (attribution)
2. Phân tích và đánh giá phân tách lợi nhuận (attribution)
3. Lập báo cáo phân tách lợi nhuận (attribution)
4. Trình duyệt phê duyệt phân tách lợi nhuận (attribution)
5. Lưu trữ hồ sơ phân tách lợi nhuận (attribution)

## 4. Input / Output
Input: Dữ liệu thị trường/hệ thống. Output: Báo cáo, hồ sơ hoàn thiện.

## 5. Vai trò (Roles)
Chuyên viên, Trưởng bộ phận, Ban Giám đốc.

## 6. Hệ thống (Systems)
Bloomberg, FiinPro, ERP, Hệ thống lõi (Core system).

## 7. Tần suất (Frequency)
Hàng ngày / Tuần / Tháng.

## 8. Điểm gãy điển hình (Pain points)
Thao tác thủ công, phân tán dữ liệu, thiếu tích hợp hệ thống tự động. `[INFERENCE]` Suy luận từ thực trạng ngành.

## 9. Ràng buộc pháp lý (Legal)
