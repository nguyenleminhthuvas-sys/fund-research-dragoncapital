# BO.3.3 - Giải đáp Khiếu nại

**Khối:** Dịch vụ NĐT & Báo cáo (Investor Services)

## 2. Trigger (Kích hoạt)

2. Phân tích và đánh giá giải đáp khiếu nại
3. Lập báo cáo giải đáp khiếu nại
4. Trình duyệt phê duyệt giải đáp khiếu nại
5. Lưu trữ hồ sơ giải đáp khiếu nại

## 4. Input / Output
Input: Dữ liệu thị trường/hệ thống. Output: Báo cáo, hồ sơ hoàn thiện.
